# Eval suite

Behavioural evals for the review skill, run with Claude Code's plugin evaluation command from
the plugin root (`claude plugin eval .`; it runs on your own account, and `--help` lists the
options, including `--tag smoke` for a quick subset and `--ablation none` to skip the
without-plugin arm). The review skill needs two tool grants passed with `--allow-tools`: the
Write tool, to save a pasted plan to a file, and the analyzer script
`skills/review/scripts/analyze_plan.py`, as a Bash pattern.

Each case directory holds `prompt.md` (the plan JSON pasted the way a person would paste it),
`resources/plan.json` (the same fixture, also used by `tests/test_fixtures.py`), and `graders/`:
the verdict word, the resource address, the fix phrase, that the `review` skill produced the
answer (`skill-fired`), and an LLM rubric on the explanation. `pasted-text-plan` has no JSON: it
checks the manual path on human-readable `terraform plan` output.

Cases are generated by `tests/gen_evals.py`; edit that file rather than the case files (this
README is not generated). The regex graders are deliberately loose (they only check that the
right words are in the reply); the LLM rubric carries the judgement. Read a failing case's
transcript before blaming the skill: a paraphrased verdict or a fix expressed differently is
usually a grader problem.
